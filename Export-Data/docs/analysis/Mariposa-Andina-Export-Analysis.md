## Key Findings

### Strengths:
1. Consistent export activity: 210 shipments over 22 months
2. Diverse fruit portfolio: 6-7 active frozen fruit products
3. Premium products: Avocado and lúcuma at $4+ per kg
4. Flexible packaging formats

### Concerns:
1. **Extreme market concentration:** 88.5% to Chile
2. **Limited European presence:** Only 3 countries, 4 shipments total
3. **Vegetable portfolio inactive**
4. **Small scale:** ~64 tons/month average
5. **High volatility:** Large month-to-month variations

### vs. Chavin de Huantar:
- Scale: 10% of Chavin's export value ($3.8M vs $36.6M)
- Volume: 1,402 tons vs 15,850 tons
- Price: $2.71/kg vs $2.31/kg (16% premium)

## Recommendations for European Strategy

### Due Diligence:
1. Verify aseptic capability (none in export data)
2. Confirm EU certifications
3. Assess realistic production capacity
4. Clarify vegetable product status

### Market Entry:
1. Start with proven products: lúcuma, chirimoya, blueberries
2. Test markets: Italy showed receptiveness
3. Set realistic volume expectations (60-80 tons/month)
4. Premium positioning for unique Andean fruits

### Key Questions:
